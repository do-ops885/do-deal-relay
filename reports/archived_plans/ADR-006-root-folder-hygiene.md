# ADR-006: Root Folder Hygiene and Temporary File Management

## Status
Proposed

## Context
The root directory of the `do-deal-relay` repository has become cluttered with temporary files, specifically several `typecheck_*.txt` files. These files were likely generated by agents or scripts during development and not cleaned up. Maintaining a clean root folder is essential for repository readability and to ensure that only critical configuration and source entry points are immediately visible.

## Decision
1.  **Mandatory Temp Directory**: All temporary files, diagnostic outputs, and transient artifacts generated by agents, scripts, or manual processes MUST be placed in the `temp/` directory.
2.  **Root Folder Prohibition**: Creation of temporary, diagnostic, or non-essential files in the root directory is strictly prohibited.
3.  **Guardrail Enforcement**: The `scripts/check-directory-organization.sh` script will be updated to detect and WARN about unauthorized files in the root, specifically targeting patterns like `typecheck_*.txt`.
4.  **Agent Instruction**: `AGENTS.md` will be updated to include these hygiene rules as part of the mandatory agent workflow.

## Consequences
-   **Pros**: Improved repository cleanliness and professional structure.
-   **Pros**: Clearer distinction between source/config files and transient artifacts.
-   **Pros**: Automated detection of hygiene regressions through quality gates.
-   **Cons**: Minor overhead for scripts/agents to ensure they target the correct directory for output.
