# learn

## Purpose
Captures lessons learned from completed tasks, discoveries, and patterns to improve future agent performance. Creates a feedback loop for continuous improvement of the AI-assisted development process.

## When to Use
- After completing a non-trivial task (Phase 4 of GOAP)
- When discovering a new pattern or anti-pattern
- After resolving a difficult bug or challenge
- When a better approach is identified post-implementation

## Rules

### Lesson Capture Criteria
Capture lessons when:
1. **Novelty**: The solution involved a new pattern or technique
2. **Difficulty**: The task took significantly longer than expected
3. **Surprise**: Behavior differed from initial assumptions
4. **Reusability**: The insight applies to future tasks
5. **Risk**: A potential pitfall was discovered or avoided

### Lesson Format
Each lesson must include:
```markdown
## [Title]

**Context**: Brief description of the situation

**Discovery**: What was learned

**Impact**: Why this matters

**Action**: How to apply this going forward

**Related Files**: Paths to relevant code/docs

**Date**: YYYY-MM-DD
```

### Storage Locations
- **General Lessons**: `reports/lessons/YYYY-MM-DD-[slug].md`
- **Architecture Decisions**: `plans/adr-[number]-[title].md`
- **Bug Post-Mortems**: `reports/postmortems/[issue-number]-[slug].md`
- **Pattern Documentation**: `docs/patterns/[pattern-name].md`

## Scripts

### capture-lesson.sh
```bash
#!/usr/bin/env bash
# Captures a lesson learned with structured prompts

set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
ROOT_DIR="$(cd "${SCRIPT_DIR}/../.." && pwd)"

cd "${ROOT_DIR}"

DATE=$(date +%Y-%m-%d)
LESSON_FILE="reports/lessons/${DATE}-$(echo "$1" | tr ' ' '-' | tr '[:upper:]' '[:lower:]').md"

mkdir -p reports/lessons

cat > "$LESSON_FILE" << EOF
# Lesson Learned: $1

**Date**: ${DATE}
**Author**: $(git config user.name || echo "Agent")

## Context
<!-- Describe the situation that led to this lesson -->

## Discovery
<!-- What was learned? Be specific. -->

## Impact
<!-- Why does this matter? What problems does it solve or prevent? -->

## Action Items
<!-- Concrete steps to apply this lesson going forward -->
- [ ] 

## Related Files
<!-- Links to relevant code, docs, or issues -->
- 

## Tags
<!-- Categorize this lesson -->
Tags: #pattern #bug #optimization #architecture

---
*Generated by learn skill*
EOF

echo "📝 Lesson captured: $LESSON_FILE"
echo "✏️  Edit the file to complete the template"
```

### analyze-task.sh
```bash
#!/usr/bin/env bash
# Analyzes completed task for learning opportunities

set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
ROOT_DIR="$(cd "${SCRIPT_DIR}/../.." && pwd)"

cd "${ROOT_DIR}"

echo "🔍 Analyzing recent commits for learning opportunities..."

# Get commits since last lesson
LAST_LESSON=$(ls -t reports/lessons/*.md 2>/dev/null | head -1 || echo "")

if [ -n "$LAST_LESSON" ]; then
    LAST_DATE=$(basename "$LAST_LESSON" | cut -d'-' -f1-3)
    COMMITS=$(git log --since="$LAST_DATE" --oneline 2>/dev/null || echo "")
else
    COMMITS=$(git log -20 --oneline 2>/dev/null || echo "")
fi

if [ -z "$COMMITS" ]; then
    echo "No recent commits to analyze."
    exit 0
fi

echo "Recent commits:"
echo "$COMMITS"
echo ""
echo "💡 Consider capturing lessons for:"
echo "- Commits with 'fix' that resolved complex issues"
echo "- Commits introducing new patterns or architectures"
echo "- Commits with large diffs or many files changed"
```

## Integration Points

### With GOAP Workflow
- **Phase 4 (Synthesize)**: Mandatory lesson capture for non-trivial tasks
- Run after documentation updates, before closing task

### With Self-Learning-Feedback
The `self-learning-feedback` skill uses captured lessons to:
- Score noise levels in codebase
- Identify recurring patterns
- Update skill rules based on historical data

### With AGENTS.md
Significant discoveries should be summarized in `AGENTS.md`:
```markdown
## Discoveries (YYYY-MM-DD)
- New pattern for [X]: See `reports/lessons/YYYY-MM-DD-[slug].md`
```

## Anti-Patterns

❌ **Vague lessons**: "Sometimes things break" (not actionable)
❌ **Blame-focused**: "John's code caused issues" (focus on systems, not people)
❌ **Too late**: Capturing lessons weeks after the fact (details forgotten)
❌ **Never referenced**: Lessons filed but never consulted (defeat the purpose)

## Querying Lessons

Find relevant lessons:
```bash
# By tag
grep -r "#circuit-breaker" reports/lessons/

# By date range
ls -la reports/lessons/ | grep "2026-01"

# By keyword
grep -l "validation" reports/lessons/*.md
```
